# @jinamem/core

Storage layer for [jinamem](https://github.com/jinaico/jinamem) — persistent memory for AI agents.

Provides the `JinamemStore` interface plus a local SQLite backend (`SqliteStore`) and a client for the hosted API (`CloudStore`). Most people want [`@jinamem/mcp`](https://www.npmjs.com/package/@jinamem/mcp) instead, which uses this package under the hood.
